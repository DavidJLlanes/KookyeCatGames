Cómo jugar

Encaja las siete piezas para formar filas completas. Las filas se despejan y suman puntos; limpiar varias a la vez da una bonificación mayor.

Las piezas caen cada vez más rápido al subir de nivel. La caída rápida las fija al instante. Si la pila llega arriba, acaba la partida.

Completa las filas objetivo de cada nivel. El reto diario es igual para todos durante el día y el contrarreloj dura 120 segundos.
